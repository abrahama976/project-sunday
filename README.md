# Project Sunday

A hybrid personal AI assistant spanning:
- Next.js PWA frontend
- FastAPI local Mac worker
- Supabase backend and queue
- Future integrations with Google APIs, Perplexity, Gemini, and Ollama

## Structure

- `apps/web` — Next.js PWA
- `apps/worker` — FastAPI local worker
- `docs` — architecture and setup docs
- `supabase` — schema, config, migrations
